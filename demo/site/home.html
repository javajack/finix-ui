FAQ

Questions, answered.

Is it really free? What's the catch?
The component kit — all 140 components, every theme, the agent manifest — is MIT-licensed with no strings. Paid tiers are team tooling built around the kit, never the kit itself.
Does it work without JavaScript frameworks?
That's the whole point. It's semantic HTML, one CSS token contract, and a small vanilla JS file for behaviors. It works in Rails, Django, Laravel, Go templates, PHP — or a static .html file on a USB stick.
How is it different from shadcn/ui?
shadcn/ui is superb — for React. Finix distills the same visual language and the strongest free patterns from its ecosystem into framework-agnostic HTML/CSS/JS, and adds whole-product components (inbox, canvas, reconciliation) that no free kit ships.
Can my AI coding agent use it?
Yes — that's a first-class use case. manifest.json maps every component to its markup, classes and JS hooks, and llms.txt gives agents a condensed usage guide.
What about accessibility?
Dialogs are native <dialog> (focus trapping for free), menus use the Popover API, accordions are <details>, and every interactive component keeps keyboard and screen-reader semantics.
