2024 guidelines

Design tokens

Every color, radius and shadow in finix resolves from a CSS custom property. Components never hardcode values — they reference the token contract, which is what makes whole-product re-theming a one-line change.

Color system

Colors are expressed in OKLCH so lightness is perceptually uniform across hues. The surface ladder gives depth: background sits lowest, wells inset into surfaces, cards float above, and popovers sit highest. Never invent a gray — pick a rung.

Brand palettes override a small set of accent tokens (--primary, --ring, --chart-1…5) while the neutral ladder stays shared, which keeps every brand equally readable in both themes.

Typography

Geist for UI text, Geist Mono for data. Sizes come from a compact scale tuned for density: 13px body in components, 12px metadata, 11px labels. Numbers in tables always use the mono face with tabular spacing.

Spacing & radius

Controls are 2rem tall by default with 1.75rem and 2.25rem variants. Radius has three roles: medium for controls, large for inner containers, extra-large for cards. Mixing roles is the fastest way to make a screen feel off.

Density

The kit is deliberately compact — closer to Linear than to Bootstrap. Cards pad at 1.25rem, intra-component gaps run 0.375–0.625rem, and page sections breathe at 1.25rem.

Motion

Motion is quiet and purposeful: entry staggers, 150–250ms state transitions on an ease-out curve, and nothing that loops without meaning. Every animation is disabled under reduced-motion.
